Build a CryptoConfig for a sign/verify operation, filling in defaults from the key file’s algorithm when the user hasn’t specified a scheme.

Precedence (highest wins):

  1. Explicit --use-case or --security-level
  2. Level inferred from the key file’s algorithm
  3. Library default
