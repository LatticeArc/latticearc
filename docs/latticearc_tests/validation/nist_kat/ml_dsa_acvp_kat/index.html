NIST ACVP ML-DSA (FIPS 204) vectors: deterministic key generation (Algorithm 6, seed → pk/sk), HashML-DSA signature generation (external interface, preHash = preHash) and HashML-DSA signature verification.

§Provenance

Extracted verbatim (hex strings copied unmodified) from the NIST ACVP-Server repository, gen-val/json-files/<dir>/internalProjection.json, at commit 2972def23bf9f3680c2c531561ed9bdd0f1086ad.

Repository: https://github.com/usnistgov/ACVP-Server, path gen-val/json-files/<dir>/internalProjection.json, where <dir> and the SHA-256 of each fetched file are:

  • ML-DSA-keyGen-FIPS204: e67ee6540d40e11506c3c4e3b1f79fc1cefcd49820db99fc61f87cc8ba463baf
  • ML-DSA-sigGen-FIPS204: 72dcaf5f69853ca267ccd16af9cb40949786aca0fcfbf05d1ebeba132b93af22
  • ML-DSA-sigVer-FIPS204: a41362abd3391b4858cf5d04556b6662881b0ac90eebf886c5c7271b0baf69d5

vsId 42 in all three files. The HASH_SIGGEN_VECTORS were chosen from the external / preHash groups so that every case has a non-empty context (the LatticeArc API requires one) and uses one of the pre-hash functions PrehashAlgorithm supports at that parameter set per the FIPS 204 §5.4 strength floor (SHA2-512 / SHAKE-256 everywhere; SHA2-256 / SHAKE-128 at ML-DSA-44 only). deterministic = true groups fix rnd = 0^32; the three deterministic = false cases carry their rnd. HASH_SIGVER_VECTORS include one valid case and five NIST-mutated cases (modified commitment / hint / message) that must be rejected.

Fetched 2026-10-20. Do not edit by hand; regenerate from the source files if NIST republishes them, and update CHECKSUMS.sha256.
