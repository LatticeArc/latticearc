Determinism vectors for latticearc::hybrid::sig_hybrid::generate_keypair_from_seed (crate root: generate_hybrid_signing_keypair_from_seed).

§Provenance

Self-generated. No external reference exists for this derivation (seed → HKDF-SHA256 sub-seeds → FIPS 204 Algorithm 6 + RFC 8032 §5.1.5); the labels latticearc/v1/ml-dsa-seed / latticearc/v1/ed25519-seed are LatticeArc-specific. These values were produced by the 0.13 implementation itself on 2026-10-20 (aarch64-apple-darwin, fips204 0.4.6, ed25519-dalek 3.0.0) and are pinned so that CI on every other platform must reproduce them byte-for-byte — the “same seed gives the same keypair” requirement. The underlying FIPS 204 Algorithm 6 mapping is independently validated by the NIST ACVP KEYGEN_VECTORS in ml_dsa_acvp_kat.rs, and the Ed25519 seed → public-key mapping by the RFC 8032 vectors in latticearc/src/primitives/ec/ed25519.rs.

A change in these values is a wire-compatibility break for every seed-derived key and must be called out in the CHANGELOG.
