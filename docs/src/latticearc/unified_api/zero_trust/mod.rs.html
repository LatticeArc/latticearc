1//! Zero-trust authentication primitives.
2//!
3//! Provides challenge-response authentication with zero-knowledge proofs,
4//! proof-of-possession, and continuous session verification.
5//!
6//! # Session State Machine
7//!
8//! ```text
9//! ┌─────────────────────────────────────────────────────────────────────────┐
10//! │                    ZERO-TRUST SESSION LIFECYCLE                         │
11//! ├─────────────────────────────────────────────────────────────────────────┤
12//! │                                                                         │
13//! │                          ┌─────────────┐                                │
14//! │                          │   Created   │                                │
15//! │                          │  (Initial)  │                                │
16//! │                          └──────┬──────┘                                │
17//! │                                 │ generate_challenge()                  │
18//! │                                 ▼                                       │
19//! │                          ┌─────────────┐                                │
20//! │                          │  Challenged │                                │
21//! │                          │ (Awaiting   │                                │
22//! │                          │  Response)  │                                │
23//! │                          └──────┬──────┘                                │
24//! │                                 │                                       │
25//! │              ┌──────────────────┼──────────────────┐                    │
26//! │              │ verify_proof()   │                  │ timeout            │
27//! │              │ SUCCESS          │                  │                    │
28//! │              ▼                  │                  ▼                    │
29//! │       ┌─────────────┐           │           ┌─────────────┐             │
30//! │       │   Active    │           │           │   Failed    │             │
31//! │       │ (Verified)  │           │           │ (Rejected)  │             │
32//! │       └──────┬──────┘           │           └─────────────┘             │
33//! │              │                  │                                       │
34//! │              │ needs_verification()?                                    │
35//! │              │ (interval elapsed)                                       │
36//! │              ▼                  │                                       │
37//! │       ┌─────────────┐           │                                       │
38//! │       │  Reverify   │───────────┘                                       │
39//! │       │  (Pending)  │  re-challenge and verify                          │
40//! │       └──────┬──────┘                                                   │
41//! │              │                                                          │
42//! │       ┌──────┴──────┐                                                   │
43//! │       │ verify()    │                                                   │
44//! │       ▼             ▼                                                   │
45//! │ ┌───────────┐ ┌───────────┐                                             │
46//! │ │ Upgraded  │ │Downgraded │                                             │
47//! │ │  Trust    │ │  Trust    │                                             │
48//! │ └─────┬─────┘ └─────┬─────┘                                             │
49//! │       │             │                                                   │
50//! │       └──────┬──────┘                                                   │
51//! │              ▼                                                          │
52//! │       ┌─────────────┐                                                   │
53//! │       │   Expired   │  session_duration > max_lifetime                  │
54//! │       │ (Terminal)  │                                                   │
55//! │       └─────────────┘                                                   │
56//! │                                                                         │
57//! └─────────────────────────────────────────────────────────────────────────┘
58//!
59//! ┌─────────────────────────────────────────────────────────────────────────┐
60//! │                         TRUST LEVEL TRANSITIONS                         │
61//! ├─────────────────────────────────────────────────────────────────────────┤
62//! │                                                                         │
63//! │   ┌───────────┐    verify()     ┌───────────┐    verify()    ┌────────┐│
64//! │   │ Untrusted │ ───────────────►│  Partial  │ ──────────────►│Trusted ││
65//! │   │   (0)     │  (success)      │   (1)     │  (success)     │  (2)   ││
66//! │   └─────┬─────┘                 └─────┬─────┘                └────┬───┘│
67//! │         ▲                             ▲                          │    │
68//! │         │         downgrade()         │        downgrade()       │    │
69//! │         │◄────────────────────────────┼──────────────────────────┘    │
70//! │         │        (verification fail)  │                               │
71//! │         │                             │         verify()              │
72//! │         │                             │         (success)             │
73//! │         │                             ▼                               │
74//! │         │                      ┌─────────────┐                        │
75//! │         │                      │   Fully     │                        │
76//! │         └──────────────────────│  Trusted    │                        │
77//! │             (revoke)           │    (3)      │                        │
78//! │                                └─────────────┘                        │
79//! │                                                                       │
80//! │   Trust Score: 0 (none) → 1 (partial) → 2 (trusted) → 3 (full)       │
81//! └─────────────────────────────────────────────────────────────────────────┘
82//! ```
83//!
84//! # Challenge-Response Protocol
85//!
86//! 1. **Challenge Generation**: Server generates random nonce with complexity level
87//! 2. **Proof Construction**: Client creates ZK proof using private key + nonce
88//! 3. **Verification**: Server verifies proof without learning private key
89//! 4. **Session Update**: Trust level adjusted based on verification result
