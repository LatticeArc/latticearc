Function ct_eq

pub fn ct_eq(a: &[u8], b: &[u8]) -> bool
Expand description

Constant-time equality of two byte slices.

Use this for comparing secret or attacker-influenced values (MAC tags, derived keys, hashes of secrets) instead of ==, which exits at the first differing byte.

Slices of different lengths compare unequal and return false immediately: lengths are treated as public, so this early return is not a timing leak for fixed-size values. For slices of equal length the running time is independent of the contents and of the position of any difference. Two empty slices are equal.

When the length is known at compile time, prefer ct_eq_array.
