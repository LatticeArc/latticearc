pub fn run_power_up_tests_with_report() -> SelfTestReport
Expand description

Run power-up tests with detailed reporting.

Same sequence as run_power_up_tests — integrity test first per FIPS 140-3 §9.2.2, then the KATs / self-consistency tests — but returns a SelfTestReport capturing individual results and timings for diagnostics. On Pass this sets SELF_TEST_PASSED so the module becomes operational; on Fail it calls set_module_error so subsequent crypto-op gates reject calls.

Unlike initialize_and_test, this function does not abort the process on failure — FIPS 140-3 §9.1’s “immediate abort” requirement is the caller’s responsibility for this entry point. Inspect the returned report and abort if your deployment needs strict §9.1 behaviour, or call initialize_and_test instead.

A SelfTestReport containing individual test results and timing information.
