Expand description

Derive a key from a password with Argon2id (RFC 9106, version 0x13).

§Arguments

  • password - Password bytes. Must not be empty.
  • salt - Unique random salt, at least Argon2Params::MIN_SALT_LEN (8) bytes; Argon2Params::RECOMMENDED_SALT_LEN (16) is recommended.
  • params - Cost parameters; see Argon2Params.

§Input policy

RFC 9106 allows an empty password. This function rejects it, matching hkdf_extract’s rejection of empty input keying material: an empty password protects nothing and usually signals a caller bug. All-zero salts are rejected as a guard against uninitialised buffers, matching pbkdf2.

§Errors

  • LatticeArcError::InvalidParameter for an empty password, a salt shorter than 8 bytes or all zero, or parameters that fail Argon2Params::validate.
  • LatticeArcError::ResourceExhausted if params.memory_kib exceeds the max_argon2_memory_kib resource limit, or the working memory cannot be allocated.
  • LatticeArcError::InvalidConfiguration if the resource limits cannot be read.
