Expand description

Generate an ML-DSA keypair deterministically from the 32-byte seed ξ (FIPS 204 Algorithm 6, ML-DSA.KeyGen_internal(ξ)).

generate_keypair is FIPS 204 Algorithm 1: it draws ξ from the OS CSPRNG and calls Algorithm 6. This function skips the draw and runs Algorithm 6 on the caller’s ξ, so the same seed yields the same keypair on every platform and build — the property a seed-backed recovery flow needs. The mapping is implemented by fips204’s keygen_from_seed, which expands H(ξ || IntegerToBytes(k, 1) || IntegerToBytes(ℓ, 1), 128) into (ρ, ρ', K) exactly as Algorithm 6 step 1 specifies; the NIST ACVP ML-DSA-keyGen vectors in tests/src/validation/nist_kat/ml_dsa_acvp_kat.rs pin that mapping byte-for-byte.

Like generate_keypair, the result passes a FIPS 140-3 pairwise consistency test before it is returned.

§Security

ξ is the whole secret: anyone holding it can regenerate the signing key. Derive it from high-entropy material (the hybrid layer derives it through HKDF from a master seed) and keep the caller’s copy in a zeroizing container.

§Errors

Returns MlDsaError::KeyGenerationError if the pairwise consistency test fails.
