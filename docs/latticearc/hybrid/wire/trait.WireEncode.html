Expand description

Encode to and decode from the LatticeArc binary wire format.

Sealed: implemented only for HybridKemPublicKey, EncapsulatedKey, HybridCiphertext, HybridSigPublicKey and HybridSignature.

Largest valid encoding of this type, in bytes. Longer input is rejected with WireError::TooLarge before parsing.
