Expand description

Sign a caller-computed SHA-512 digest (pre-hashed mode).

digest is SHA-512(M) over content of any size, computed by the caller (streaming); the signer never sees M, so the message resource limit does not apply. context is required (1..=MAX_HYBRID_SIG_CONTEXT_LEN bytes). Both legs use their standard pre-hash constructions with LABEL-ph || 0x00 || context as the context string: HashML-DSA with the SHA-512 OID (FIPS 204 Algorithm 4) and Ed25519ph (RFC 8032 §5.1). SHA-512 is the only pre-hash because Ed25519ph is defined over SHA-512 and SHA-512 meets the FIPS 204 §5.4 strength floor at every ML-DSA parameter set.

A pre-hashed signature verifies only under verify_prehashed with the same context — never under verify or verify_with_context.

§Errors

Returns InvalidDigestLength if digest.len() != 64, InvalidContext if context is empty or over budget, otherwise the same errors as sign.
