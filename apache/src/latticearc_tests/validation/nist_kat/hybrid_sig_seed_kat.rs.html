9//! ## Provenance
10//!
11//! **Self-generated.** No external reference exists for this derivation
12//! (`seed → HKDF-SHA256 sub-seeds → FIPS 204 Algorithm 6 + RFC 8032 §5.1.5`);
13//! the labels `latticearc/v1/ml-dsa-seed` / `latticearc/v1/ed25519-seed` are
14//! LatticeArc-specific. These values were produced by the 0.13 implementation
15//! itself on 2026-10-20 (aarch64-apple-darwin, `fips204` 0.4.6,
16//! `ed25519-dalek` 3.0.0) and are pinned so that CI on every other platform
17//! must reproduce them byte-for-byte — the "same seed gives the same keypair"
18//! requirement. The underlying FIPS 204 Algorithm 6 mapping is independently
19//! validated by the NIST ACVP `KEYGEN_VECTORS` in `ml_dsa_acvp_kat.rs`, and
20//! the Ed25519 seed → public-key mapping by the RFC 8032 vectors in
21//! `latticearc/src/primitives/ec/ed25519.rs`.
22//!
23//! A change in these values is a wire-compatibility break for every
24//! seed-derived key and must be called out in the CHANGELOG.
