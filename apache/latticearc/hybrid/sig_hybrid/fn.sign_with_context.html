Sign with a required application context bound into both legs.

context (1..=MAX_HYBRID_SIG_CONTEXT_LEN bytes, e.g. b"vault/v1/root-sig") separates signatures made for different purposes under one key: the ML-DSA leg receives LABEL-ctx || 0x00 || context as its FIPS 204 context string and the Ed25519 leg signs SHA-512(LABEL-ctx || 0x00 || |context| || context || message). A signature verifies only under verify_with_context with the same context — never under verify or verify_prehashed.

The message is bounded by the configured signature resource limit (64 KiB by default); use sign_prehashed for larger content.

§Errors

Returns InvalidContext if context is empty or over budget, otherwise the same errors as sign.
