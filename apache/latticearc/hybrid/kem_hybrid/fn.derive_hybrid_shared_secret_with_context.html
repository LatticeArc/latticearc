derive_hybrid_shared_secret with a required application context.

The HKDF info is the context-less layout (domain, both static public keys, the ephemeral key and the KEM ciphertext, each length-prefixed) followed by [context_len: u32 BE][context]. Every field is length-prefixed and parsed left to right, so an info string with the trailing context field can never equal one without it: the two layouts are injective into distinct byte strings, and a context-bound secret is unrelated to the context-less secret for the same inputs.

§Errors

Returns HybridKemError::InvalidContext if context is empty, and the same errors as derive_hybrid_shared_secret otherwise.
