§

InvalidKeyLength

Invalid key length

§

InvalidNonceLength

Invalid nonce length — fail-closed defence-in-depth.

The Nonce type is [u8; 12], so wrong-size nonces cannot reach the AEAD trait through normal use; this variant exists to surface the case where the underlying primitive (aws-lc-rs’s try_assume_unique_for_key, or chacha20poly1305) ever rejects a 12-byte nonce — e.g. because the AEAD algorithm semantics changed upstream. Mapped to FipsErrorCode::InvalidNonce for FIPS error reporting. See test_invalid_nonce_length_is_structurally_unreachable for the structural-unreachability proof.

§

WeakKey

Key material is structurally weak and was rejected before any cryptographic operation. Currently raised for the all-zero key, which usually indicates uninitialised memory or an unset configuration field rather than a deliberate choice. The AEAD algorithm itself does not fail on this input — the rejection is a fail-closed defence in depth.

EncryptionFailed(String)

Encryption failed

DecryptionFailed(String)

Decryption failed

§

InvalidSegmentSize

Streaming AEAD segment size outside stream::MIN_SEGMENT_SIZE..=stream::MAX_SEGMENT_SIZE. Caller-side configuration error, not adversary-reachable.

§

InvalidSegmentLength

A plaintext handed to the streaming encryptor has the wrong length for its position: every non-final segment must be exactly the plaintext segment size and the final segment must not exceed it. Caller-side error on the encrypt path only; decrypt-side length mismatches collapse into AeadError::DecryptionFailed.

§

SegmentCounterExhausted

The 32-bit segment counter cannot advance past u32::MAX. The encryptor refuses to seal a non-final segment that could never be followed, and the sequential decryptor refuses to advance; the counter never wraps.

§

StreamExhausted

The sequential decryptor was asked for another segment after the one flagged as final was accepted.

§

EmptyContext

The caller-supplied context / associated data was empty. Every stream and every wrapped key must be bound to a non-empty purpose string.

§

AmbiguousLabels

The segmented AEAD’s record-key and record-AAD labels are equal or one is a prefix of the other, so a key-derivation info could equal a record’s associated data. Caller-side configuration error.

§

WeakGeneration

The segmented AEAD generation is all zero, which indicates an unset value rather than a fresh per-version salt. Caller-side configuration error.

§

InvalidPaddedLength

wrap_key_padded was asked for a total length that cannot hold the wrapped key, or one above key_wrap::MAX_WRAPPED_LEN.

§

MalformedEncoding

A byte string handed to WrappedKey::from_bytes does not have the documented shape (bad version byte or impossible length). This is a structural check on public bytes and is deliberately distinct from AeadError::DecryptionFailed, which covers every key-dependent failure.
