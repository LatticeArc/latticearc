Struct StreamDecryptor

pub struct StreamDecryptor { /* private fields */ }
Expand description

Streaming decryptor with random access.

new parses the header and verifies the key commitment; it fails under a wrong key before any segment can be opened. After that, open_segment decrypts any segment by index and open_next walks the stream sequentially.

pub fn new(key: &[u8; 32], aad: &[u8], header: &[u8]) -> Result<Self, AeadError>

Parses header, verifies the key commitment under key and derives the segment cipher bound to aad.

§Errors
  • AeadError::EmptyContext if aad is empty.
  • AeadError::WeakKey if key is all zero.
  • AeadError::DecryptionFailed for every other failure: wrong header length, unknown version or flags, segment size out of range, commitment mismatch (wrong key or tampered header), oversize aad or key-derivation failure. These are deliberately indistinguishable.

pub fn open_segment( &self, index: u32, segment: &[u8], is_last: bool, ) -> Result<Zeroizing<Vec<u8>>, AeadError>

Decrypts the segment at index. segment is ciphertext || tag exactly as returned by the encryptor, and is_last must be true for the segment produced by StreamEncryptor::finish.

Random access is safe: each call verifies the segment against this stream’s header hash, the index and the last flag.

§Errors

AeadError::DecryptionFailed if the segment has an impossible length for its position, belongs to another stream or index, has the wrong last flag, or fails AES-GCM authentication. These are deliberately indistinguishable.

Source

pub fn open_next( &mut self, segment: &[u8], is_last: bool, ) -> Result<Zeroizing<Vec<u8>>, AeadError>

Decrypts the next segment in sequence. The internal counter advances only on success; after the final segment (is_last == true) is accepted, further calls fail.

§Errors
  • AeadError::StreamExhausted after the final segment was accepted.
  • AeadError::SegmentCounterExhausted if a non-final segment at index u32::MAX was accepted and the counter cannot advance.
  • AeadError::DecryptionFailed as for open_segment.
