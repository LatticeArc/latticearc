pub fn encrypt_hybrid(
    public_key: &HybridKemPublicKey,

) -> Result<Vec<u8>, LatticeArcError>
Expand description

Encrypts plaintext to public_key (hybrid KEM + AES-256-GCM) and returns the wire-encoded ciphertext. aad is authenticated but not encrypted.

§Errors

InvalidInput for plaintext above the library’s size cap.
